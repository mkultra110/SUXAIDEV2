# SUXAI — Static Audit (read-only, no fixes applied yet)

**Branch** `claude/french-greeting-lGwbV` · **HEAD** `3d1c807` (v0.11.1) · **Date** 2026-04-25

Audit of the production codebase against the 15 categories (A→O) defined in
the audit prompt. **No code was modified during this pass.** Each finding
points at a real file:line and includes a one-sentence reproducer.

Severity legend:

- **CRITICAL** — security flaw, key leak, disk corruption, Anthropic invariant
  violation causing a guaranteed 400.
- **HIGH** — reproducible functional bug blocking a primary flow.
- **MEDIUM** — UX/perf regression (cache miss systemic, listener leak).
- **LOW** — style, TODO, unclear error message.
