# SUXAI — Static Audit (v0.12.2, read-only)

**Branch** `claude/french-greeting-lGwbV` · **HEAD** `7d66999` (v0.12.2) · **Date** 2026-04-26

Fresh static audit on v0.12.2, covering the 15 categories A–O defined in the
audit mandate. **No code modified.** Each line points at a real `file:line`
and includes a one-sentence reproducer plus a one-liner fix proposal. The
v0.11.1 audit is archived at `docs/audit/static-audit-v0.11.1.md` for diff —
13 of its 35 findings have been resolved between v0.11.2 and v0.12.2 (see
"Resolved since v0.11.1" at the bottom).

Severity legend:

- **CRITICAL** — security flaw, key leak, disk corruption, Anthropic
  invariant violation causing a guaranteed 400, or fully disabled core
  feature.
- **HIGH** — reproducible functional bug blocking a primary flow.
- **MEDIUM** — UX/perf regression (cache miss systematic, listener leak).
- **LOW** — style, todo, unclear error message, theoretical edge case.
